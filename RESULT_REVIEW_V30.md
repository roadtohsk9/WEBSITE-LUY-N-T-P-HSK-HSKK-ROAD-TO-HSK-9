# EIT IELTS V30 — Result / Answer / Explanation Review

- Tick/submit button opens confirmation modal with **Submit Now** and **Check again**.
- Reading and Listening submissions redirect to `practice-result.html` after successful save.
- Results show correct / wrong / skipped / accuracy and estimated IELTS band.
- Answer review is separated by Reading PASSAGE 1–3 or Listening SECTION 1–4.
- Each question shows user's answer versus correct answer with green/red states.
- Completion/Summary answers use a blue correct-answer treatment.
- Explanation page is separated by passage/section.
- Each group can have a shared explanation entered by Admin (`groupExplanation` / `explanation`).
- Each question has its own collapsible **EXPLANATION** button; click again to close.
