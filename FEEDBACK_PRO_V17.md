# EIT V17 — Feedback & PRO visibility

- Writing/Speaking submissions now support detailed teacher feedback attached to each submission.
- Admin can score skills, enter criteria, task/part comments, strengths, improvements and next steps, then publish feedback to the learner.
- Student result API only returns feedback when `feedback_published=true`.
- Active PRO entitlements automatically hide PRO purchase/up-sell UI on public/practice pages. The UI returns once entitlement is absent/expired.
- Course-enrolled users continue to receive course-derived PRO through the existing `grantCoursePro` flow.
