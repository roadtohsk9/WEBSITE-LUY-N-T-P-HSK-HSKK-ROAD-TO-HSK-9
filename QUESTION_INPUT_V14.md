# EIT Question Input Improvements

## Reading / Listening completion builder
- Dedicated visual row builder for Summary, Note, Form, Table, and Sentence Completion.
- Each row has question number, text before the blank, answer, text after the blank, and explanation.
- FROM/TO controls automatically resize the question range and preserve in-range data.
- Live preview shows the IELTS-style number + blank layout.

## Listening Map / Plan / Diagram
- Upload a map/plan/diagram image directly from the admin Question Group.
- Preview the uploaded image before saving.
- The saved image is rendered above the questions in the student test.
