# EIT IELTS V16 – Listening UX Fix

- Listening practice tests now use a single full-width exam surface; the split divider is Reading-only.
- Listening section navigation switches SECTION 1–4 and shows question buttons for the active section.
- Listening completion groups have a dedicated IELTS-style form layout with inline numbered blanks.
- Summary/Note/Form/Table/Sentence completion groups remain data-driven through question groups.
- Listening Map/Plan/Diagram groups render their uploaded image in the full-width listening surface.
- Listening text selection now supports the same highlight cycle as Reading: first brown, second pink, third removes highlight.
- Saved Listening highlights persist per test in localStorage.
- Highlight and Note selection tools work on Listening content, including completion text.
- Added clearer spacing, summary sheets, section banners, and question cards for Listening.
- Reading split-pane resizer remains unchanged.
