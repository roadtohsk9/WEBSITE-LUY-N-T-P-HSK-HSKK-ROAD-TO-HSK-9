EIT IELTS — PRACTICE IMPORT FORMAT

1) FILE WORD
- Mỗi câu bắt đầu bằng: 1. ... / 2. ...
- Đáp án lựa chọn có thể dùng A. ... B. ... C. ... D. ...
- Sau phần câu hỏi đặt heading: ANSWER KEY
- Sau đó mỗi dòng: 1. B / 2. grey / 3. TRUE
- Sau đó heading: EXPLANATIONS
- Mỗi dòng: 1. Giải thích...

2) CHẤM ĐÁP ÁN
- Không phân biệt hoa/thường: grey = GREY = Grey.
- Có phân biệt dấu câu: grey khác grey.
- Chỉ bỏ khoảng trắng thừa ở đầu/cuối đáp án.
- Với Multiple Choice, answer key B/C... có thể khớp với option tương ứng.
